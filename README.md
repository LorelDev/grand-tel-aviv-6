# Grand Tel Aviv 6

משחק עולם פתוח בתל אביב, בדפדפן. הכול נבנה בקוד (Three.js) — בעזרת Fable 5.2
**לשחק:** https://grand-tel-aviv-6.web.app

## מה יש במשחק

- הליכה, ריצה ונהיגה בעיר חיה: תנועה, רמזורים, הולכי רגל, יום ולילה, מזג אוויר.
- חטיפת רכבים (`F` ליד רכב), אגרופים ברחוב (`X`).
- רמת מבוקשות עד חמישה כוכבים, ניידות שרודפות, מעצר וקנס.
- משימות: הזמנה מעוזי (גניבת רכב למוסך), נהג מילוט, משלוח דחוף.

## מקשים

`WASD` תנועה · `Shift` ריצה / בוסט · `F` רכב / חטיפה · `X` אגרוף · `M` מפה · `Q`/`E` מצלמה · `Esc` תפריט

## הרצה מקומית

```bash
npm install
npm run dev      # http://localhost:5196
npm run build    # → dist/
npm run deploy   # בנייה + פריסה ל-Firebase Hosting
```

## מבנה

- `src/main.js` — מסך הפתיחה והפעלת המשחק.
- `src/game3d/favors/` — העיר, הדמויות, הרכבים והפיזיקה.
- `src/game3d/favors/gta.js` — מבוקשות, משטרה, הולכי רגל.
- `src/game3d/favors/gta-missions.js` — המשימות.
